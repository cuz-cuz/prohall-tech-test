# Conversas com IA

Esta pasta referencia conversas relevantes usadas no desenvolvimento.

## Regras

- não copiar tokens, cookies, senhas, arquivos `.env` ou dados pessoais;
- preferir resumo, link exportado ou captura sanitizada;
- registrar a decisão tomada, não apenas a sugestão da IA;
- manter os materiais pequenos o suficiente para revisão humana.

## Registro inicial

- A conversa inicial identificou que o primeiro plano tratava de um desafio incorreto de quiz capilar.
- A captura desktop do enunciado mostrou que o desafio real é uma loja virtual baseada em DummyJSON.
